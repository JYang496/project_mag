# Weapon Pixel-Art Style Samples

This directory contains review previews and the machine-readable validation
manifest for the production weapon sprites. The files in this directory are
not referenced by runtime weapon scenes or data resources.

## Locked direction

- Orthographic top-down weapon view with the muzzle or blade pointing up.
- Actual sprite canvas: `48x64` pixels.
- High-tech, super-deformed mecha equipment language: compact modules,
  oversized readable functional parts, layered armor, and strong silhouettes.
- Hard pixel clusters only. No antialiasing, blur, subpixel edges, gradients,
  texture noise, cast shadows, or baked recoil.
- Static weapon art. Runtime code remains responsible for recoil and feedback.
- Near-white armor and deep navy mechanical structure unify the weapon family.
- Each weapon uses at most 12 visible colors, including outline colors.
- Every weapon has the exact same 13x13 near-circular crystal socket and
  four-ray diamond-cross facet pattern. Only its three crystal colors change
  to communicate the weapon attribute.

## Shared palette roles

| Role | Hex |
| --- | --- |
| Deep outline | `#040F1B` |
| Bevel edge | `#0A1D2C` |
| Deep structure | `#142B3A` |
| Gunmetal | `#2F4753` |
| Mid metal | `#567079` |
| Light metal | `#8EA8B0` |
| Armor shade | `#C2D3DA` |
| Armor white | `#EFF6F8` |
| Specular white | `#FFFFFF` |

## Attribute accents

| Attribute | Accent direction |
| --- | --- |
| Kinetic / ballistic | amber, gold, signal red |
| Beam / electric | cyan, cobalt, pale blue-white |
| Freeze | ice cyan, cobalt, deep cold blue |
| Fire / heat | orange, vermilion, hot yellow |
| Plasma | violet, magenta-red, pale lavender |
| Support / field | teal, green, pale mint |

The attribute colors are accents rather than full-body recolors. Armor and
structure colors remain shared so all weapons read as one manufactured family.
The production set follows the approved concept-art silhouettes and uses up to
12 visible colors per weapon. All 17 runtime sprites use an identical `48x64` transparent
canvas. Narrow silhouettes use transparent side padding instead of changing
their authored resolution. Functional attack parts stay visually dominant;
secondary armor, tanks, magazines, and guards remain compact.

## Review and validation files

`weapon_set_preview.png` shows all 17 production sprites at a common pixel
scale. `weapon_sprite_manifest.json` records each native canvas size, visible
color count, attribute group, and crystal-core coordinate.

## Generation provenance

The built-in ImageGen workflow produced one independently redrawn concept per
weapon on a removable magenta background. The production builder reconstructs
each concept on the common 48x64 canvas, maps it to the shared role palette,
and stamps the deterministic shared core. The concepts are preserved under
`asset/images/weapons/concepts_hd/`; the runtime sprites are generated by
`tools/pixel_art/generate_weapon_sprites.mjs`.
