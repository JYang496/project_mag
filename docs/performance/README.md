# 武器技能测试场性能测试

从主菜单进入“武器技能测试场”，点击面板顶部的“性能测试 · 全武器极限敌群”。测试会自动生成 120 个真实敌人，并依次让模拟玩家使用全部武器移动、持续攻击及释放可用技能。每把武器预热 3 秒、采样 10 秒；过程中无需操作。测试完成后，面板显示报告路径。

报告保存在 `docs/performance/weapon_lab/run_<时间>_<序号>/`：`summary.md` 是概览，`suite_summary.json` 与每把武器的 JSON 包含帧时间、卡顿次数、实体数量和可测量的集中模拟耗时。请在可写的项目工作目录中从 Godot 编辑器运行；导出的只读游戏包无法写入项目 `docs` 目录。

这是固定高压场景，不模拟第一关的刷怪、奖励或战斗结束规则。报告中的处理/物理监视器可能重叠或滞后；未测到的耗时不能直接归因于渲染，也不能将这些监视器相加计算精确占比。
