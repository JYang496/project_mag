RUNTIME RULES

运行规则摘要

候选池与权重

  • 奖励、特殊掉落和休息区商店共同使用 ModuleOfferCatalog。
  • 新层模组在开放后的两个关卡机会内获得 3 倍候选权重。
  • 关卡 3、6、9 开始时，奖励优先保证一个满足现有武器、槽位、替换和重复限制的新层模组。
  • 已拥有满级模组仍会从新的奖励候选池排除。
  • 旧存档已经持有的高层模组不会被移除；分层只限制未来产出。
  • 奖励卡和商店会为刚开放层级的模组显示 NEW。
