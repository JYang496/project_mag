# Combat Feedback Showcase

Launch from the project root:

```powershell
& 'E:\Godot_v4.7.1-stable_win64\Godot_v4.7.1-stable_win64_console.exe' --path . res://tests/showcases/combat_feedback/combat_feedback_showcase.tscn
```

Inspect the four warning footprints, damage hierarchy, status text, directional
damage wedge, health thresholds, shield deltas, skill-ready rail, and weapon heat
states. The scene uses runtime feedback components over synthetic combat clutter;
it does not validate a complete battle or gameplay timing.
