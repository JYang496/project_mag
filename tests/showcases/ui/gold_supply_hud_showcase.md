# 金币补给 HUD 手动预览

从项目根目录运行：

```powershell
& 'E:\Godot_v4.7.1-stable_win64\Godot_v4.7.1-stable_win64_console.exe' --path . res://tests/showcases/ui/gold_supply_hud_showcase.tscn
```

按 `1`–`6` 查看积累中、首次就绪、多份就绪、选择中、菜单阻挡和应用反馈。
按 `L` 切换中英文；按 `G` 或点击领取按钮查看选择中状态。窗口保持打开，供重复检查。

检查独立面板与生命 HUD、右下热量条的间距，下一份进度与待领取数量的区别，
就绪音、图标回弹、按键底板呼吸，以及阻挡领取时的静态提示。

预览复用实际 `UI.tscn`、补给控制器、生命组件和热量组件。
经济与生命数值使用示例数据，并关闭 UI 主循环的数据刷新；领取操作仅切换预览状态。
选择中和菜单阻挡使用暂停状态模拟，不执行真实战斗、奖励应用或存档操作。
该场景是手动视觉工具，未注册为自动测试。

可选 `-- --capture-dir=<绝对目录>` 保存中英文各六种状态的画面，完成后窗口仍保持打开。
