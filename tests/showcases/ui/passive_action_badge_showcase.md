# Passive action badge showcase

Launch from the repository root:

```powershell
& 'E:\Godot_v4.7.1-stable_win64\Godot_v4.7.1-stable_win64_console.exe' --path . res://tests/showcases/ui/passive_action_badge_showcase.tscn
```

Review the five operation semantics: next fire, reload, swap to main hand,
countdown, and release skill. Press `1` through `5` or the on-screen buttons to
advance individual states. Press Space to pause or resume the automatic cycle.

Each card shows a doubled inspection preview and the actual HUD-size badge. This
is an isolated presentation gallery using the production badge scene; it does
not execute weapon combat logic or validate gameplay triggers.
